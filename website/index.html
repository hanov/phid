What is phid?

phid helps security teams find signs of protected health information (PHI) and personally identifiable information (PII) in supported AWS resources, then investigate how that data may be exposed or accessed. It runs from your terminal using read-only AWS access and saves findings and supporting evidence in a local database.

Use it to review sensitive-data risks and generate an HTML dashboard for investigation or sharing. Optional local AI helps interpret the evidence; phid does not automatically change your AWS resources.

Quick start

Full documentation →
# Read the built-in manual
phid --man

# Scan and generate an HTML dashboard
phid scan --html scan-report.html

# Generate a report from stored findings
phid report --html scan-report.html

Configure your AWS credentials and review the example configuration before scanning. Evidence is stored in local SQLite — no PHI or PII is copied; the database records where to look in AWS, not the data itself.

  • Read-only discovery. Inspect supported AWS resources, exposure, and access relationships.
  • Local AI, if you want it. Connect to your existing local Ollama, or work without an LLM.
  • Portable reports. Export findings, coverage, incidents, and evidence as standalone HTML.
  • Just a CLI. Python engine, no application server, no web API layer.

Installation notes

macOS Apple Silicon — manual installation

Download phid, then run:

mkdir -p "$HOME/.local/bin"
install -m 755 ~/Downloads/phid "$HOME/.local/bin/phid"
export PATH="$HOME/.local/bin:$PATH"
phid --version

Add the PATH line to your shell profile for future sessions. No Python installation is needed for this binary.

macOS Intel & Ubuntu — from source

Install Python 3.9+ with pip and venv support, then download and extract the source archive. From its directory:

tar -xzf phid-2.0.1-source.tar.gz
cd phid-2.0.1
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
phid --man
Windows — from source (PowerShell)

Install Python 3.9+ and extract the source archive. Open PowerShell in the extracted phid-2.0.1 folder:

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\phid.exe --man

Source installation downloads Python dependencies. Optional spaCy and in-process GGUF inference require extra dependencies; they are not bundled in the standalone binary. AWS credentials and models are not included.
